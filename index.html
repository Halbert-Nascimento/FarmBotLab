Referência de Comandos da API

  • moverDireita() — move o bot uma célula para a direita
  • moverEsquerda() — move para a esquerda
  • moverCima() — move para cima
  • moverBaixo() — move para baixo
  • plantar("tipo") — planta na célula atual: capim, trigo, milho, arvore, girasol, morango
  • colher() — colhe o que está na célula atual

Aliases em inglês também funcionam: moveRight(), moveLeft(), moveUp(), moveDown(), plant(), harvest()
